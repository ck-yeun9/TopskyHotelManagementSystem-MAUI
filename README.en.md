# :exclamation: Important Notice:

**The project is developed using .NET 10 MAUI and currently focuses exclusively on the Android platform, as other platforms are not available for testing at this stage.**

# :thought_balloon: Development Purpose:

This mobile application, developed in conjunction with the hotel management system, primarily assists users in:

- Querying room availability
- Making reservations
- Staying up-to-date with the latest hotel news and announcements
- Rating their stay experience,
  among other functions.

# :mag_right: System Development Environment:

Operating System: Windows 11(x64)

Development Tools: Microsoft Visual Studio 2022 (latest version of the system)

Database: SQLite

Programming Languages: C# language, T-SQL language

Development Platform: .Net

Development Framework: .Net 10

Development Technology: .NET 10 MAUI
